## 代码启动命令流程

### basic

1. 进入工作空间
2. ```colcon build```
3. ```source install/setup.bash```
4. ```ros2 launch ros2_homework_basic_package going_8.launch.py```

### advanced

1. 进入工作空间
2. ```colcon build```
3. ```source install/setup.bash```
4. ```ros2 launch publish_maker_package publish_maker.launch.py```
> 启动接收坐标并转换为rviz2三维模型的功能包，同时打开RViz2
5. 在RViz2中添加by TOPIC - /visualization_maker_array/MakerArray
6. 新建一个终端，重复第3步
7. ```ros2 bag play ./src/map_to_visualize```
> 开启bag回放
